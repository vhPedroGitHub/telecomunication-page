Simulador 8051

Ensamblador compatible con la sintaxis del curso (ASEM-51 / MCU 8051 IDE): ORG, EQU, DB, DW, END, etiquetas, $, HIGH()/LOW(), números 0Fh, 1010b, 'A'. JMP/CALL genéricos se ensamblan como LJMP/LCALL. Modelo: 8051/8052 con 256 bytes de RAM interna, ciclo de máquina configurable. Atajos: F7 paso, Alt+F7 atrás, F5 ejecutar/pausar.

Puertos

Cada pin muestra su nivel (latch AND dispositivo externo). El interruptor de debajo, cerrado, lleva el pin a «0». En P0 puede fijarse además un byte de entrada (p. ej. el dato de un conversor A/D).

Display de 7 segmentos

Conexión del curso: segmento a → bit 0, b → bit 1, …, g → bit 6, dp → bit 7.
